RUANG EKONOMI — WEBSITE BELAJAR UTS

Cara membuka di HP Android:
1. Download file index.html.
2. Buka aplikasi File Manager dan cari index.html di folder Download.
3. Ketuk file tersebut, lalu pilih Chrome atau browser lain.
4. Website berjalan secara offline. Tidak perlu install aplikasi atau koneksi internet.

Fitur:
- Materi mengikuti kisi-kisi foto dan materi pertemuan 1–7.
- Penjelasan konsep, contoh kasus, dan langkah hitungan.
- Grafik permintaan-penawaran yang berubah saat harga digeser.
- Kalkulator keseimbangan pasar, surplus, elastisitas, dan biaya produksi.
- Simulasi pergeseran kurva dan grafik biaya produksi interaktif.
- Kuis 8 soal dengan umpan balik dan penjelasan jawaban.

Catatan:
- Contoh elastisitas pada foto kisi-kisi menggunakan metode nilai awal.
- Materi PPT pertemuan 4 juga menampilkan metode titik tengah. Keduanya disediakan terpisah di kalkulator agar tidak tertukar.
- Untuk hasil hitung UTS, tetap ikuti metode yang diminta dosen atau tertulis pada soal.
